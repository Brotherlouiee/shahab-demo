# پرسشنامه سنجش متغیرهای رفتاری

## پرسش ۱: محل مصرف وام

**سؤال**

پولی که از این وام یا اعتبار به دست می‌آورید را دقیقاً در چه راهی صرف می‌کنید؟

| رتبه    | گزینه                                                                                    |
| ------- | ---------------------------------------------------------------------------------------- |
| بیشترین | مستقیماً برای کار، تولید یا خرید تجهیزاتی که درآمدم را بیشتر می‌کند سرمایه‌گذاری می‌کنم. |
| زیاد    | برای حفظ ارزش پولم در برابر تورم، دارایی‌هایی مثل طلا، ارز یا سهام می‌خرم.               |
| متوسط   | برای خرید کالاهای اساسی و ضروری زندگی (مثل لوازم خانگی یا تعمیرات مهم) هزینه می‌کنم.     |
| کم      | برای ارتقای سطح زندگی و خریدهای غیرضروری (مثل سفر، گوشی جدید یا لوازم لوکس) خرج می‌کنم.  |
| کمترین  | فقط برای پرداخت بدهی‌های قبلی یا پاس کردن چک‌های برگشتی از آن استفاده می‌کنم.            |

---

## پرسش ۲: واکنش در صورت لغو وام

**سؤال**

اگر دریافت این وام لغو شود و نتوانید آن را بگیرید، برای رفع نیازتان چه می‌کنید؟

| رتبه    | گزینه                                                                                                    |
| ------- | -------------------------------------------------------------------------------------------------------- |
| بیشترین | به هر قیمتی شده (حتی با قرض گرفتن از بازار آزاد با سود بسیار بالا) پول را جور می‌کنم چون نیازم فوری است. |
| زیاد    | فوراً بخشی از دارایی‌های باارزشم (مثل طلا یا ماشین) را می‌فروشم تا کارم راه بیفتد.                       |
| متوسط   | سعی می‌کنم یک کالا یا خدمات ارزان‌تر پیدا کنم تا با بودجه فعلی‌ام هم‌خوانی داشته باشد.                   |
| کم      | خرید را چند ماه عقب می‌اندازم تا خودم کم‌کم پولش را پس‌انداز کنم.                                        |
| کمترین  | کلاً از این خرید یا اقدام منصرف می‌شوم، چون اصلاً عجله‌ای ندارم و ضروری نیست.                            |

## پرسش ۳: اولویت در انتخاب وام

**سؤال**

در انتخاب یک وام، کدام حالت برای شما در اولویت اول قرار دارد؟

| رتبه    | گزینه                                                                                 |
| ------- | ------------------------------------------------------------------------------------- |
| بیشترین | فقط کمترین سود ممکن برایم مهم است؛ حاضرم ماه‌ها در نوبت بمانم و چند ضامن ببرم.        |
| زیاد    | سود پایین مهم‌تر است، اما به شرطی که شرایط ضامن آوردن بیش از حد سخت نباشد.            |
| متوسط   | تعادل برایم مهم است؛ سودی منطقی با دردسر و زمان انتظار متوسط.                         |
| کم      | سرعت و راحتی مهم‌تر است؛ حاضرم سود کمی بالاتر بدهم اما درگیر کاغذبازی و ضامن نشوم.    |
| کمترین  | فقط و فقط دریافت فوری و بدون ضامن برایم مهم است؛ اصلاً به مبلغ سود نهایی فکر نمی‌کنم. |
