# Shahab recommendation-engine delivery checklist

- [ ] Source documents are inventoried and data audit passes or reports approved exceptions.
- [ ] Questionnaire uses canonical IDs Q1–Q6/S7/S8/S10/S13.
- [ ] All eight loan variables and categories are normalized and versioned.
- [ ] Engine is pure, deterministic and produces an explainability trace.
- [ ] Empty-branch pruning, path aggregation, normalization and the 50% threshold are tested.
- [ ] UI distinguishes no candidates from user-filtered zero results.
- [ ] Build, static checks and E2E pass.
- [ ] Pull request records unresolved data decisions and test results.
