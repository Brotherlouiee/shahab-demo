# US-09.T081 — آزمون واقعی API روی Docker محلی

**وضعیت: بخشی از ماتریس اجرا شد؛ پذیرش آنلاین و تسک کامل نیستند.** به دستور مالک، محیط آزمایشی فقط روی لپ‌تاپ در WSL/Docker است. هیچ محیط، حساب SSH، تونل، گواهی یا تنظیم تازه‌ای روی سرور ساخته نشد و production تغییر نکرد. زیرساخت authority انتشار داده/config آماده نیست؛ import و publish انجام نشد.

## محیط و جداسازی

- پروژهٔ Compose محلی `shahab-t081-local` با API، PostgreSQL و Redis سالم اجرا شد. API فقط روی `127.0.0.1:8000` در دسترس است؛ این URL نشانی آنلاین دو آزمونگر نیست.
- volume تازهٔ `shahab-t081-local_postgres_data` از volume موجود `shahab-demo_postgres_data` جداست. پروژه و دادهٔ قبلی دست‌نخورده ماندند. migration دیتابیس تازه به `ff11b02f0001 (head)` رسید.
- تصویر API فقط در Docker محلی build شد؛ هیچ image منتشر یا روی سرور مستقر نشد. کاتالوگ و config منتشرشده در این دیتابیس وجود ندارند.
- Swagger محلی `/docs` و قرارداد `/api/v1/openapi.json` هر دو ۲۰۰ دادند. قرارداد ۱۷ عملیات محصول و دو health route، جمعاً ۱۹ مسیر، دارد.

## درخواست‌های واقعی و نتیجه

آزمون‌ها با دو حساب آزمایشی و cookie jar مستقل روی PostgreSQL واقعی محلی اجرا شدند. شماره، کد، cookie، token، payload، شناسهٔ خصوصی و پاسخ پرسشنامه ثبت نشده‌اند. برای OTP فقط mock مجاز محیط local استفاده شد؛ این آزمون مالکیت واقعی شماره یا ارسال SMS را اثبات نمی‌کند.

در اجرای اول، ابزار موقت آزمون هنگام قطع کوتاه اتصال در restart خطای polling داد؛ این خطای ابزار بود. شرط انتظار اصلاح و همان مسیر دوباره اجرا شد و با کد خروج صفر پایان یافت. فایل ابزار موقت وارد Git نشده است. زمان دقیق تک‌درخواست‌ها، آزمون browser/دو آزمونگر آنلاین، انقضای واقعی نشست و موفقیت توصیه/وام/تاریخچه/نشان ثبت یا اجرا نشده‌اند.

## موارد باز

پذیرش آنلاین T081 مسدود است، چون مالک محیط را به لپ‌تاپ محدود کرده و دسترسی محدود مستقل برای آزمونگر دوم آنلاین وجود ندارد. انتشار داده/config مصوب نیز به authority محافظت‌شده و نقش‌های لازم وابسته است که فعلاً آماده نیست. بنابراین توصیهٔ موفق، جزئیات وام منتشرشده، تاریخچهٔ دارای داده، hide، bookmark موفق و ماندگاری آن‌ها هنوز شاهد واقعی ندارند. OTP واقعی و مالکیت شماره نیز تا تأیید الگو و مجوز ارسال آزموده نمی‌شوند. CI یا سالم‌بودن کانتینر این خلا را پر نمی‌کند. **US-09.T081 باز می‌ماند.**
