# کنترل‌های نتیجهٔ توصیه‌گر

## محدودهٔ US-09.T04

این تسک یک مرز نمایشیِ آمادهٔ اتصال می‌سازد؛ صفحهٔ فعالِ prototype و نتیجه‌های ثابت آن را به دادهٔ جعلی جدید تبدیل نمی‌کند. اتصال session و endpoint واقعی به این صفحه در `US-09.T06` انجام می‌شود.

## کنترل‌ها

- فیلتر دستی فقط بر «نام بانک» در `rankedRecommendations` اعمال می‌شود.
- خروجی فیلتر، زیرمجموعه‌ای با همان ترتیب سرور است؛ بنابراین حالت `zeroAfterFilter` همچنان دقیق تشخیص داده می‌شود.
- مرتب‌سازی نمایش یا «ترتیب پیشنهادی سامانه» است یا «نام بانک (الفبا)». مرتب‌سازی روی score وجود ندارد.
- sort نام بانک stable است؛ در نام برابر، ترتیب ورودی سرور حفظ می‌شود.
- `needsReview` از گزینه‌های رتبه‌بندی‌شده جدا می‌ماند و score یا rank دریافت نمی‌کند.

## دسترس‌پذیری و RTL

`RecommendationResultScreen` دارای `dir="rtl"`، عنوان سطح اول، labelهای متصل به selectها، focus-visible، وضعیت‌های `loading` و `error` با role مناسب و اعلان زندهٔ تعداد نتایج است. CSS آن در `src/App.css` responsive است و کنترل‌ها را در نمایش کوچک تک‌ستونه می‌کند.

## محدودیت‌های صریح

- browser score را محاسبه، normalize، threshold یا رتبه‌بندی نمی‌کند.
- تبدیل مقدار server-supplied بین صفر و یک به درصد صرفاً formatting نمایش است.
- این تسک API، session، persistence، نتیجهٔ ثابت جدید، route فعال یا deploy ایجاد نمی‌کند.
- endpoint واقعی و آزمون دستی URL قابل‌آزمایش در `US-09.T06` شرط Done داستان هستند.
